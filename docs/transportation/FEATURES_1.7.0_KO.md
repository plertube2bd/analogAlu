# Redstone Transportation 1.7.0 변경 사항

## 직접 지은 구조물이 움직입니다

블록으로 지은 구조물에 코어를 붙이고 우클릭하면 통째로 움직이는 탈것이 됩니다. 멈춘 뒤 Shift+우클릭하면 블록으로 돌아옵니다. 자세한 내용은 [`STRUCTURE_GUIDE_KO.md`](STRUCTURE_GUIDE_KO.md)에 있습니다.

- **엘리베이터**: 위아래로 움직입니다. 호출기를 우클릭하거나 신호를 넣으면 그 층으로 옵니다.
- **배**: 물 위를 다닙니다. 땅에 닿으면 멈춥니다.
- **비행선**: 어디로든 날아갑니다. 블록 16개마다 부양 풍선이 1개 필요합니다.

## 새 블록과 아이템

- 엘리베이터 코어, 선박 조타기, 비행선 조타기
- 부양 풍선, 엘리베이터 호출기
- 구조 범위 지정기: 벽에 붙은 엘리베이터처럼 주변까지 딸려 올 때 범위를 직접 정합니다

## 구조물 동작

- 구조물은 최대 1024블록입니다. 지형 블록은 따라오지 않습니다.
- 상자 내용물을 포함해 블록이 그대로 보존되고, 저장 후 다시 열어도 유지됩니다.
- 갑판 위를 걸어 다닐 수 있고, 플레이어와 몹이 구조물을 따라 움직입니다.
- 회전한 뒤 되돌리면 가장 가까운 90도 방향으로 놓이고 블록 방향도 함께 돌아갑니다.
