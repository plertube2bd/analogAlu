# Redstone Transportation 1.4.2 변경 사항

## 방향 표시 수정
- 설치 시 모든 방향성 장치의 앞면과 출력 화살표가 설치자를 향하도록 배치 방향을 통일했습니다.
- 출력/가속 로직과 모델 방향은 동일한 FACING 상태를 참조합니다.
- 빈손 Shift+우클릭으로 북→동→남→서 순서로 90도 회전할 수 있습니다.
- 정거장은 일반 우클릭으로 출발, Shift+우클릭으로 방향 회전합니다.

## 작동 상태 시각화
- 모터: 꺼짐(단계별 기본색), 레드스톤 입력 대기(노랑), 전차 가속 중(초록).
- 축전기: 비어 있음(회색), 충전 중(청록), 충전량 보유(초록).
- 이동수단 제어기: 신호 전달 중 전면 표시 녹색.
- 방향성 신호 중계기: 신호 전달 중 전면 표시 청록색.
- 정거장: 전차 감지 중 전면 표시 녹색.
- 활성/대기 상태에 따라 블록이 빛을 방출하도록 했습니다.

## 기존 기능 유지
- 모터 I~IV 최고속도는 21/43/72/103m/s입니다.
- `tram_coupler` 제작법은 `minecraft:iron_chain`을 사용합니다.
- 전차 연결, 네 단계 모터, 레시피 및 모든 기존 등록을 유지했습니다.

## 검증 범위
- 모든 JSON 문법 및 로컬 모델/텍스처 참조 검사.
- blockstate의 모든 상태 조합이 모델에 연결되는지 검사.
- Java 25 및 Minecraft 26.3 클라이언트가 없어 Gradle 컴파일/실행 테스트는 수행하지 않았습니다.
