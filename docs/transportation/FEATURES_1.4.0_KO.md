# Redstone Transportation 1.4.0 — 변경 사항

## 모터 4단계

- 모터 I: 21 m/s (1.05 블록/틱), 축전기 20틱마다 1 충전량 소비
- 모터 II: 43 m/s (2.15 블록/틱), 축전기 12틱마다 1 충전량 소비
- 모터 III: 72 m/s (3.60 블록/틱), 축전기 8틱마다 1 충전량 소비
- 모터 IV: 103 m/s (5.15 블록/틱), 축전기 4틱마다 1 충전량 소비
- RedstoneTramEntity의 공통 레일 속도 상한을 5.15 블록/틱으로 상향
- 모터 IV 블록/아이템, 블록 상태, 모델, 네더라이트 스타일 텍스처 추가

## 제작법

- 모터 III: 모터 II + 레드스톤 블록 2개 + 다이아몬드 6개. 네더라이트 재료를 제거.
- 모터 IV: 모터 III + 레드스톤 블록 2개 + 네더라이트 주괴 4개 + 다이아몬드 2개.
- 전차 연결기의 재료 ID는 `minecraft:iron_chain`으로 유지.

## 블록별 인게임 설명

- 이동수단 제어기: 주변 신호를 읽고 바라보는 방향으로 0~15 출력.
- 모터 I~IV: 전용 전차 가속, 각 단계별 최고 속도 및 축전기 소모 간격 표시.
- 아날로그 축전기: 입력 충전, 최대 15, 바라보는 방향 출력, 인접 모터가 소비.
- 전차 정거장: 빈손 우클릭으로 전차 출발, 전차 도착 시 방향 출력 15.
- 신호 중계기: 주변 입력 중 가장 강한 신호를 바라보는 방향으로 전달.
- 전차: 전용 탑승 가능 차량, 바닐라 레일/모터/연결기 지원.
- 연결기: 전차 두 대를 순서대로 선택해 연결, Shift+우클릭으로 해당 전차 연결 해제.

## 세계 생성/레시피 버그 수정 유지

- 이전 로그에서 확인된 `minecraft:chain` 미등록 오류를 `minecraft:iron_chain`으로 수정한 상태를 유지.
- 모든 레시피 JSON 문법과 모드 자체 ID 참조 검사.

## 검증 한계

정적 JSON 및 리소스 참조 검사는 수행합니다. 현재 실행 환경에는 JDK 25가 없어 Minecraft 26.3용 Gradle 빌드와 실제 게임 주행 테스트는 완료할 수 없습니다.
