# 1.3.1 수정 및 1.3.0 기능 요약

- 전차 연결기 아이템 추가
- 전차 간 양방향 연결 목록을 엔티티 저장 데이터에 보존
- 연결된 전차 사이 간격을 spring/damper 방식으로 보정
- 전차 1대당 최대 2개의 연결부 지원
- 같은 열차 내부 순환 연결 방지
- Shift + 연결기 우클릭으로 해당 전차의 모든 연결 해제
- 모터 I/II/III 세 단계 추가 및 단계별 가속/최고 속도/축전기 소비 밸런스 적용
- 모터 II/III 텍스처, 아이템 모델, 블록 상태 및 제작법 추가
- 전차 연결기 텍스처, 아이템 모델, 제작법 추가


## 1.3.1 수정

- 전차 연결기 레시피의 재료 ID를 `minecraft:chain`에서 `minecraft:iron_chain`으로 수정. Minecraft 26.3에서 `minecraft:chain`은 더 이상 유효한 아이템 ID가 아니므로, 이전 ID를 사용하면 `minecraft:recipe` 레지스트리 로딩이 실패합니다.
