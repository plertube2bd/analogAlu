# Redstone Transportation 1.9.0 변경 사항

## 발전과제

발전과제 화면에 **레드스톤 운송** 탭이 생겼습니다. 월드에 들어가면 바로 보입니다. 표에서 ★는 도전 과제이고 경험치 100을 줍니다.

### 철도

| 발전과제 | 달성 조건 |
|---|---|
| 첫 번째 모터 | 레드스톤 전차 모터를 만든다 |
| 레일이 곧 엔진 | 동력 선로를 만든다 |
| 두 번만 클릭하세요 | 선로 부설기를 만든다 |
| 승차 완료 | 레드스톤 전차에 탄다 |
| 열차 편성 | 전차 연결기로 카트 두 대를 연결한다 |
| 화물 수송 | 화물 전차를 만든다 |
| 아날로그 운전대 | ALU 전차 제어기를 만든다 (Analog ALU가 있을 때만 나타납니다) |
| 최고 출력 | 레드스톤 전차 모터 IV를 만든다 |
| 시속 360킬로미터 ★ | 카트를 타고 모터 IV로 초속 100미터에 도달한다 |

### 공장

| 발전과제 | 달성 조건 |
|---|---|
| 나무꾼의 은퇴 | 벌목기를 만든다 |
| 끝없는 벨트 | 컨베이어 벨트를 만든다 |
| 공장장 | 공장 제어기에 기계 3대 이상을 연결한다 |
| 땅 밑으로 | 채굴 드릴을 만든다 |

### 화로

| 발전과제 | 달성 조건 |
|---|---|
| 더 뜨겁게 | 강화 화로, 용광로, 훈연기 중 하나를 만든다 |
| 불꽃의 정점 | III단계 강화 블록을 만든다 |
| 화덕의 주인 ★ | III단계 화로, 용광로, 훈연기를 모두 만든다 |

### 구조물

| 발전과제 | 달성 조건 |
|---|---|
| 통째로 움직이기 | 구조물을 조립한다 |
| 올라갑니다 | 엘리베이터를 조립한다 |
| 진수식 | 배를 조립한다 |
| 하늘을 나는 집 | 비행선을 조립한다 |
| 자동 항해 | 배나 비행선이 항로 표지에 도착한다 (64칸 안에 있으면 달성) |
| 항해 중 수리 | 움직이는 구조물에 블록을 놓는다 |
| 거대 건조물 ★ | 블록 500개 이상으로 구조물을 조립한다 |

## 기존 월드

이미 지어 둔 구조물로는 달성되지 않습니다. 조립, 연결 같은 행동을 새로 해야 합니다. 아이템 발전과제는 인벤토리가 바뀔 때 달성됩니다.
