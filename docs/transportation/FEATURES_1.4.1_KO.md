# 1.4.1 변경 내용

- 플레이어가 획득할 수 있는 모든 블록과 운송 아이템의 툴팁 설명을 여러 줄로 확장했습니다.
- 이동수단 제어기, 모터 I~IV, 아날로그 축전기, 정거장, 신호 중계기, 레드스톤 전차, 전차 연결기의 사용 조건과 주의사항을 한국어/영어로 추가했습니다.
- 모터별 최고속도와 축전기 소비 주기를 툴팁에 계속 표시합니다.
- 툴팁 외 게임 로직, 레시피, 블록 등록 및 전차 연결 동작은 변경하지 않았습니다.
- 내부 표시용 `redstone_tram_body`는 별도 아이템이 아니므로 게임 내 툴팁이 아닌 설명서에 용도를 기록했습니다.
## 1.4.2 방향 표시 및 작동 상태 표시

- 모터, 축전기, 제어기, 신호 중계기, 정거장은 설치할 때 앞면/방향 화살표가 설치자 쪽을 향합니다.
- 빈손으로 Shift+우클릭하면 방향이 시계 방향으로 90도 회전합니다. 회전 후 화살표와 실제 출력/가속 방향은 같은 `FACING` 상태를 사용합니다.
- 모터 표시: 레드스톤 신호만 들어오면 노란색 대기 표시, 전차에 실제 가속력을 적용하면 초록색 작동 표시가 켜집니다.
- 축전기 표시: 충전 중에는 청록색, 저장된 전력이 남아 있으면 초록색, 비어 있으면 어두운 회색으로 표시됩니다.
- 이동수단 제어기/방향성 신호 중계기: 신호를 통과시키는 동안 전면 표시가 초록색/청록색으로 바뀝니다.
- 정거장: 전차를 감지하는 동안 전면 표시가 초록색으로 바뀝니다.
- 상태에 따라 실제 빛도 방출합니다. 대기 표시와 활성 표시의 밝기는 서로 다릅니다.

### 방향 조작

1. 블록을 설치하면 화살표가 설치자 쪽을 향합니다.
2. 방향을 바꾸려면 빈손으로 블록을 바라보고 Shift+우클릭합니다.
3. 한 번 누를 때마다 북→동→남→서 순서로 90도 회전합니다.
4. 정거장은 일반 빈손 우클릭이 전차 출발이므로, 방향을 바꿀 때만 Shift+우클릭을 사용합니다.
