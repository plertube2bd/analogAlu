# 1.4.4 레일 옆 블록 충돌 수정

## 수정 내용
- 전차 엔티티의 충돌 폭을 1.35블록에서 0.98블록으로 줄였습니다.
- 높이 0.90블록과 전차 렌더링 모델은 유지했습니다.
- 레일 바로 옆에 돌, 흙, 유리 등 일반 블록을 설치해도 전차 충돌 상자와 겹치지 않도록 했습니다.
- 전차 속도, 모터 단계, 연결 기능, 조합법 및 툴팁은 변경하지 않았습니다.

## 원인
기존 1.4.3에서 전차 폭이 1.35블록이었습니다. 레일 중심 기준 좌우로 0.675블록을 차지하여 인접 블록의 충돌 영역(레일 중심에서 0.5블록부터 시작)과 0.175블록 겹쳤습니다.

## 빌드 및 테스트
JDK 25와 프로젝트에 지정된 Gradle/Loom 환경에서 `BUILD_WINDOWS.bat` 또는 Gradle 빌드를 실행하세요. 이 작업 환경에는 JDK 25가 없어 실제 게임 실행 테스트는 수행하지 못했습니다.
