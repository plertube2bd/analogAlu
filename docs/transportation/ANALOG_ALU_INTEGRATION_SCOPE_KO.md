# Analog ALU 연동 범위 (Redstone Transportation 1.6.1, Analog ALU 0.1.2)

1.6.0부터 ALU 신호는 전차뿐 아니라 동력 선로, 공장 기계, 공장 제어기도 제어합니다. ALU 전차 제어기를 화살표가 동력 선로로 향하게 붙이면 모터와 같은 네 채널이 작동합니다. 공장 쪽 연결은 [`AUTOMATION_GUIDE_KO.md`](AUTOMATION_GUIDE_KO.md)를 참고하세요.

## 전차 제어에 연결된 Analog ALU 기능

- **Copper Wire:** 0~15 신호를 전달합니다. 제공된 JAR의 `MAX_DISTANCE` 상수는 32입니다. 0.1.2의 잠금 기능은 전선끼리의 연결만 막으므로, 전선 끝에 놓인 전차 제어기, 동력 선로, 기계로 가는 출력에는 영향이 없습니다.
- **Adder / Subtractor:** 4비트 속도 명령을 계산합니다. Carry/Borrow 출력은 1비트 제어 신호로 활용할 수 있습니다.
- **AND / OR / XOR:** 0~15 값의 비트 단위 연산으로 속도 마스크, 허가 조건, 방향 선택을 계산합니다.
- **Logical AND / OR / XOR (0.1.2):** 입력이 0인지 아닌지로 판정해 0 또는 15를 출력합니다. 우클릭하면 NAND/NOR/XNOR로 바뀝니다. 운행 허가, 비상 제동, 공장 가동 조건에 알맞습니다.
- **Logical NOT / Bitwise NOT:** 각각 0/비0 조건 반전과 4비트 전체 반전에 사용합니다.
- **Shift Left / Shift Right:** 속도 명령을 2배(4비트 범위 내) 또는 절반으로 조정합니다.
- **CRAM:** 4비트 속도·운행 명령을 저장합니다.
- **Extender:** 입력 신호를 그대로 전달합니다.

## ALU 전차 제어기 채널

제어기 화살표는 모터를 향합니다.
- 뒤: 속도 0~15
- 왼쪽: 운행 허가 (0=정지 명령, 1~15=허가)
- 오른쪽: 후진 (0=정방향, 1~15=후진)
- 위: 비상 제동 (1~15=제동)
- 앞: 인접 모터로 속도 출력

## 전기 회로

ALU 0.1.5 이상의 전기 회로를 읽습니다. 블록에 닿은 `copper_cable`의 전압을 세기로 바꾸며, 12V가 세기 15입니다. 전압만 읽을 뿐 회로의 부하로 참여하지는 않으므로, 소비 전력은 ALU의 부하 블록이 정합니다. 자세한 내용은 [`ELECTRIC_GUIDE_KO.md`](ELECTRIC_GUIDE_KO.md)에 있습니다.

## 정거장 자동 출발

정거장은 탑승이 일어나면 신호 15를 화살표 방향으로 출력하고, 카트 유무(0 또는 15)는 비교기로 읽습니다. 화살표 방향을 제외한 면에서 0→1 이상의 입력 상승 에지를 감지해 옆 상자의 전차 한 대를 출발시킵니다. Logical NOT과 AND를 조합하면 '정거장이 비어 있고 출발 요청이 있을 때'만 출발시키는 회로를 만들 수 있습니다.

## 아직 연결되지 않은 Analog ALU 기능

- Upward Hopper: 일반 컨테이너처럼 기계의 아이템을 주고받는 코드 경로를 쓰지만, 1.6.0 화물 전차와의 직접 연동은 시험하지 않았습니다.
- Mass Analyzer 및 반도체 제조 블록: 제조/분석 기능이며 전차의 주행 제어에는 직접 사용하지 않습니다.
- Programmed Silicon Wafer: 0.1.2부터 웨이퍼 프로그램을 컴파일하고 실행할 수 있지만, 플레이어가 손에 든 웨이퍼를 실행하는 방식이고 입력 포트가 0으로 고정되어 있습니다. 월드의 신호를 읽거나 내보내는 블록이 없어서 전차나 공장과 연결할 지점이 아직 없습니다.

## 선택적 의존성

`analog_alu` Java 클래스를 직접 참조하지 않고 Minecraft 블록 레지스트리 ID와 0~15 레드스톤 API로 연결합니다. 따라서 Analog ALU가 설치되지 않아도 기본 전차 기능은 로드됩니다. ALU 전차 제어기 제작법은 `fabric:all_mods_loaded` 리소스 조건으로 Analog ALU가 설치된 경우에만 등록됩니다.
